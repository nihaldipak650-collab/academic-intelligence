## 1. `(供参考）大学物理C复习提纲(5).pdf`

| 维度 | 内容 |
|------|------|
| **主要覆盖** | 全册 13 章要点、公式、概念清单 [`第1–28页`] |
| **适合学生** | 已上过课、需系统串知识点的高年级/医学生（**根据内容推断**） |
| **适合环节** | 理解串讲、查漏、考前速看 |
| **怎么用** | 按章浏览：先读标题与公式框，合上回忆，再对照 [`第N页`] 核对 |

| **前置** | 高中力学、代数、基本微积分（**课件明确写了** 多处含导数/积分表述） |
| **不适合** | 零基础首学、纯刷计算（缺例题步骤） |
| **下一步** | 期中卷对应页 → `pdf_json.json`；电磁/光学 → 两道大题 MD |
