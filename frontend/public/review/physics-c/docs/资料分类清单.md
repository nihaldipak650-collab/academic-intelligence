# 本站资料说明

给补考同学看的：这个速成站上**已经能打开什么**、**怎么用**。

---

## 先刷什么（推荐顺序）

1. **2026 期中卷 + 官方答案**（PDF，可在线预览）
2. **保姆级解析**（卡步骤时看：期中 / 光学 / 电磁）
3. **2022–2024 下学期真题**（Word，需下载后用 WPS 打开）
4. **复习提纲**（28 页 PDF，考前过一遍）
5. **黄本练习册答案**（34 份 PDF，有题目再对着对）

## 打不开时

- **PDF**：点「下载」保存后再开
- **Word 试卷**：点「下载试卷」，用 WPS 或 Word 打开
- **保姆级 / 本页**：应显示排版好的阅读页，不是满屏 `#` 和表格符号——若还是源码，刷新或换浏览器试试

更细的复习路线，回速成站首页按「几天能过」「按专题」走即可。
