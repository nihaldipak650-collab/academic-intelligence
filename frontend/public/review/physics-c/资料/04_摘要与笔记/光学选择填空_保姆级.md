## 一、薄膜干涉（增透膜 / 减反膜）

### 核心公式

| 目标 | 垂直入射条件 | 记忆 |
|------|--------------|------|
| **反射减弱**（增透） | $2nd = (k+\frac12)\lambda$ | 半波损失 → 相差 $\lambda/2$ |
| **反射加强** | $2nd = k\lambda$ | 无半波损失或相消后加强 |
| **透射减弱** | 与反射加强条件相关 | 题面说「透射减弱」→ 常对应反射加强 |

**最小厚度：** 取 $k=0$ 或 $k=1$ 看题意（「最小」→ 从小 $k$ 试）。

### 典型卷面

- 玻璃上镀膜 $n=1.25$，$\lambda=600\text{ nm}$，求不反射的最小厚度 → **2020 下选择**
- 白光垂直照射 $n=1.5$ 薄膜，反射加强波长 → **填空，多卷重复**
- 空气中薄膜，反射加强最小厚度 → **选择/填空**

### 易错

- 光程是 $nd$，不是几何厚度 $d$  alone  
- 「减弱反射」≠「减弱透射」，读清问的是哪一束光

## 二、双缝干涉 · 盖膜移位

### 核心

在缝 $S_1$ 前加厚度 $d$、折射率 $n$ 的薄膜：

$$\Delta \delta = (n-1)d$$

（**不是** $nd$：要减去被膜取代的空气光程 $d$。）

**零级明纹**向加盖膜一侧平移。

### 典型卷面

- 双缝 $D=1.2\text{ m}$，$d=0.5\text{ mm}$，$\lambda=500\text{ nm}$，求第 5 级明纹坐标 → **填空**
- 盖膜后零级明纹向**上/下**移动 → **填空**

### 保姆级步骤

1. 写出原光程差 $\delta = d\sin\theta \approx dx/D$  
2. 一侧加 $(n-1)d$ → 新零级满足 $\delta + (n-1)d = 0$  
3. 判断条纹向盖膜侧移动

## 三、偏振 · 马吕斯定律

### 核心公式

**线偏振光过偏振片：** $I = I_0 \cos^2\theta$（$\theta$ = 振动方向与透振方向夹角）

**自然光过第一片偏振片：** $I_1 = \frac{1}{2}I_0$（与角度无关）

**多片级联：** 逐片算，每片的 $\theta$ 是**相邻两片透振方向的夹角**，不是实验室绝对角。

### 典型卷面

- 两偏振片夹 $60^\circ$，中间插入第三片各成 $30^\circ$ → **多卷填空**
- 四片每片转 $30^\circ$ → **2020/2021 下选择**
- 自然光 + 线偏振混合，旋转检偏器最大/最小比 5:1 → 求成分比 → **选择**

### 三级片例题模板

起偏器与检偏器成 $60^\circ$，透射 $I_1$。中间插入偏振片与前两者均 $30^\circ$：

1. 由 $I_1$ 反推 $I_0 = 8I_1$（若起点是自然光）  
2. 自然光 → 第一片：$I_0/2$  
3. 第二片相对夹 $30^\circ$：$\times\cos^2 30^\circ$  
4. 第三片相对夹 $30^\circ$：$\times\cos^2 30^\circ$

## 四、布儒斯特角（起偏角）

### 核心

$$\tan i_0 = \frac{n_2}{n_1}$$

当入射角 $= i_0$ 时：

- **反射光** = 完全线偏振光（振动平行于界面）  
- **折射光** = 部分偏振光  
- **反射线与折射线夹角 = 90°**（$i_0 + \gamma = 90^\circ$）

### 典型卷面

- 自然光以布儒斯特角入射，反射光偏振态 → **选择**
- 已知完全偏振反射，求折射角 → **填空**（常用 $30^\circ$ 等互余角）

## 五、光栅 · 迈克尔逊（选择常考）

| 考点 | 公式/结论 |
|------|-----------|
| 光栅方程 | $d\sin\theta = k\lambda$ |
| 缺级 | $k = \frac{d}{a} \cdot k'$（$a$ 缝宽） |
| 最高级次 | $k_{\max} < d/\lambda$ |
| 迈克尔逊 | 动镜移 $\lambda/4$ → 条纹移 1 条 |

**大题**见 `光学大题_保姆级逐题解析.md` 第 1、4 题。

## 六、简约眼 · 配镜（选择 + 大题）

### 标准参数（题面常给）

- 角膜曲率半径 $r$，眼内折射率 $n \approx 1.33$，眼轴 $L$  
- **焦度** $D = 1/f$（单位：屈光度，$f$ 用米）  
- **近视**：远点在近处 → 凹透镜；**远视**：近点过远 → 凸透镜

### 大题

见 `光学大题_保姆级逐题解析.md` 第 5–6、9 题。

### 选择速判

- 使无穷远成像于视网膜 → 配镜使组合焦度补偿屈光不正  
- 简约眼模型：单球面折射近似
