## 模块一：静电场与导体介质

### 1. 带电球体内偏心空腔电场（2020年下/2012-13年下 原题）
**【题目】** 一球体内均匀分布着电荷体密度为 $\rho$ 的正电荷，保持分布不变，在球内挖去半径为 $r$ 的偏心小球体，两球心距离 $OO' = d$。求空腔内任意点 $P$ 处的电场强度。

**【详细解析】**
1. **公式与参数概览：** 
   | 物理思想 | 核心公式 | 说明 |
   | :--- | :--- | :--- |
   | **补偿法(叠加原理)** | $\vec{E} = \vec{E}_{\text{完整球}} + \vec{E}_{\text{负电球}}$ | 将挖去空腔等效为“完整的正电荷球”叠加“小体积的负电荷球” |
   | **均匀带电球内部场强** | $\vec{E} = \frac{\rho}{3\varepsilon_0}\vec{r}$ | 由高斯定理 $\oint \vec{E}\cdot d\vec{S} = \frac{q}{\varepsilon_0}$ 导出 |

2. **分步计算过程：**

   **💡 第一步：构建完整球体的电场**
   设空腔内任意点 $P$，其相对于大球球心 $O$ 的位置矢量为 $\vec{r_1}$。
   完整大球在 $P$ 点产生的场强：
   $$\vec{E_1} = \frac{\rho}{3\varepsilon_0}\vec{r_1}$$

   **💡 第二步：构建“负电荷小球”的电场**
   设 $P$ 点相对于小球（空腔）球心 $O'$ 的位置矢量为 $\vec{r_2}$。
   填充的等效负电荷（密度 $-\rho$）在 $P$ 点产生的场强：
   $$\vec{E_2} = \frac{-\rho}{3\varepsilon_0}\vec{r_2}$$

   **💡 第三步：矢量叠加得总场强**
   根据矢量合成法则，空腔内 $P$ 点的总场强为：
   $$\vec{E} = \vec{E_1} + \vec{E_2} = \frac{\rho}{3\varepsilon_0}(\vec{r_1} - \vec{r_2})$$
   由矢量三角形关系可知 $\vec{r_1} - \vec{r_2} = \vec{OO'} = \vec{d}$，因此：
   $$\vec{E} = \frac{\rho}{3\varepsilon_0}\vec{d}$$
   *结论：这是一个极其经典的结论，空腔内部是一个**大小和方向均恒定的匀强电场**！*

### 2. 同心导体球壳静电感应（2023年下/2013-14年下 原题）
**【题目】** 真空中，半径 $R_1$ 的导体球外套一个内外半径为 $R_2$、$R_3$ 的导体球壳。内球带电 $+Q$，外球壳带电 $+q$。求（1）场强分布；（2）导体球电势；（3）系统静电能。（取无穷远电势为0）

**【详细解析】**
1. **分步计算过程：**

   **💡 第一步：分析电荷分布（静电感应法则）**
   - 内球表面（$r=R_1$）：带电 $+Q$
   - 球壳内表面（$r=R_2$）：由于静电感应，带电 $-Q$
   - 球壳外表面（$r=R_3$）：由电荷守恒，原带电 $q$，加上被内表面排斥出来的 $+Q$，总电荷为 $Q+q$

   **💡 第二步：利用高斯定理求各层场强 $E$**
   作半径为 $r$ 的同心高斯球面：
   - $r < R_1$ (内球内部)：导体内部无场，$E_1 = 0$
   - $R_1 < r < R_2$ (球间空隙)：仅包围内球电荷 $+Q$，则 $E_2 = \frac{Q}{4\pi\varepsilon_0 r^2}$
   - $R_2 < r < R_3$ (壳层内部)：导体内部，$E_3 = 0$
   - $r > R_3$ (整个系统外部)：包围总电荷 $Q+q$，则 $E_4 = \frac{Q+q}{4\pi\varepsilon_0 r^2}$

   **💡 第三步：积分求内导体球电势 $U_1$**
   电势等于场强从该处到无穷远的线积分（跳过场强为0的区域）：
   $$U_1 = \int_{R_1}^{\infty} E dr = \int_{R_1}^{R_2} E_2 dr + \int_{R_3}^{\infty} E_4 dr$$
   $$U_1 = \int_{R_1}^{R_2} \frac{Q}{4\pi\varepsilon_0 r^2} dr + \int_{R_3}^{\infty} \frac{Q+q}{4\pi\varepsilon_0 r^2} dr$$
   $$U_1 = \frac{Q}{4\pi\varepsilon_0}\left(\frac{1}{R_1} - \frac{1}{R_2}\right) + \frac{Q+q}{4\pi\varepsilon_0 R_3}$$

   **💡 第四步：求系统静电能 $W_e$**
   利用电场能量密度 $w_e = \frac{1}{2}\varepsilon_0 E^2$ 体积分：
   $$W_e = \int_{R_1}^{R_2} \frac{1}{2}\varepsilon_0 \left(\frac{Q}{4\pi\varepsilon_0 r^2}\right)^2 4\pi r^2 dr + \int_{R_3}^{\infty} \frac{1}{2}\varepsilon_0 \left(\frac{Q+q}{4\pi\varepsilon_0 r^2}\right)^2 4\pi r^2 dr$$
   $$W_e = \frac{Q^2}{8\pi\varepsilon_0}\left(\frac{1}{R_1} - \frac{1}{R_2}\right) + \frac{(Q+q)^2}{8\pi\varepsilon_0 R_3}$$

### 3. 平行长直导线电势差与电容（2022年下/2026年上 原题）
**【题目】** 两根半径均为 $a$、相距为 $d$ ($d \gg a$) 的无限长平行直导线，带等量异号电荷，线电荷密度分别为 $\pm\lambda$。求两者电势差及单位长度的电容。

**【详细解析】**
1. **分步计算过程：**

   **💡 第一步：求两导线连线上的叠加场强**
   设正导线在 $x=0$，负导线在 $x=d$。连线上任一点 $x$ 处的场强为两者叠加（方向均向右，相加）：
   $$E(x) = E_+ + E_- = \frac{\lambda}{2\pi\varepsilon_0 x} + \frac{\lambda}{2\pi\varepsilon_0 (d-x)}$$

   **💡 第二步：对电场积分求两导线电势差 $U$**
   积分路径从正导线表面 ($x=a$) 到负导线表面 ($x=d-a$)：
   $$U = \int_a^{d-a} E(x) dx = \frac{\lambda}{2\pi\varepsilon_0} \int_a^{d-a} \left(\frac{1}{x} + \frac{1}{d-x}\right) dx$$
   $$U = \frac{\lambda}{2\pi\varepsilon_0} \left[ \ln x - \ln(d-x) \right]_a^{d-a} = \frac{\lambda}{2\pi\varepsilon_0} \left[ 2\ln(d-a) - 2\ln a \right]$$
   化简得到 $U = \frac{\lambda}{\pi\varepsilon_0} \ln\frac{d-a}{a}$。
   因题目已知 $d \gg a$ ，近似得 $U \approx \frac{\lambda}{\pi\varepsilon_0} \ln\frac{d}{a}$。

   **💡 第三步：求单位长度电容 $C_0$**
   根据定义，取长度为 $L$ 的导线，其电荷量 $Q = \lambda L$，该段电容 $C = \frac{Q}{U}$。
   单位长度电容：
   $$C_0 = \frac{C}{L} = \frac{\lambda}{U} = \frac{\lambda}{\frac{\lambda}{\pi\varepsilon_0}\ln\frac{d}{a}} = \frac{\pi\varepsilon_0}{\ln(d/a)}$$

## 模块二：稳恒磁场与电磁感应

### 4. 非均匀磁场中的安培力积分（2024年下/2013-14年下 原题）
**【题目】** 长直导线通电流 $I_1$。其旁有共面垂直线段 $ab$，长为 $l$，通电流 $I_2$。$a$ 端距直导线距离为 $d$。求 $ab$ 整体受到的安培力。

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 描述 | 公式原型 |
   | :--- | :--- | :--- |
   | **长直导线磁场** | 距导线 $x$ 处磁感应强度 | $B = \frac{\mu_0 I_1}{2\pi x}$ |
   | **安培力微元** | 电流元 $I_2 dx$ 处于磁场中 | $dF = I_2 B dx$ |

2. **分步计算过程：**

   **💡 第一步：切片建立微分方程**
   在 $ab$ 棒上取距直导线为 $x$ 处，长度为 $dx$ 的微元。
   该处磁场由 $I_1$ 激发，大小为 $B = \frac{\mu_0 I_1}{2\pi x}$。
   电流元受到的安培力微元 $dF = I_2 B dx = \frac{\mu_0 I_1 I_2}{2\pi x} dx$。

   **💡 第二步：对整根导体棒积分**
   受力区间从近端 $x=d$ 到远端 $x=d+l$：
   $$F = \int_d^{d+l} \frac{\mu_0 I_1 I_2}{2\pi x} dx = \frac{\mu_0 I_1 I_2}{2\pi} [\ln x]_d^{d+l}$$
   $$F = \frac{\mu_0 I_1 I_2}{2\pi} \ln\frac{d+l}{d}$$

### 5. 交变磁场中的互感与感生电动势（2021年下 第24题）
**【题目】** 无限长直导线通交变电流 $i = I_0 \sin\omega t$，旁有共面矩形线圈（长 $l$，宽 $b-a$），近端距直导线为 $a$。求（1）穿过线圈的磁通量 $\Phi_m$；（2）线圈中的感应电动势 $\varepsilon$。

**【详细解析】**
1. **分步计算过程：**

   **💡 第一步：写出随时间变化的磁场**
   距离直导线 $r$ 处的磁感应强度：
   $$B(r, t) = \frac{\mu_0 i}{2\pi r} = \frac{\mu_0 I_0 \sin\omega t}{2\pi r}$$

   **💡 第二步：通过积分求总磁通量 $\Phi_m$**
   取面积微元 $dS = l \cdot dr$（设 $l$ 为与直导线平行的边）。
   $$\Phi_m = \int B dS = \int_a^b \frac{\mu_0 I_0 \sin\omega t}{2\pi r} l dr$$
   提出与积分变量 $r$ 无关的项：
   $$\Phi_m = \frac{\mu_0 l I_0 \sin\omega t}{2\pi} \int_a^b \frac{dr}{r} = \frac{\mu_0 l I_0 \sin\omega t}{2\pi} \ln\frac{b}{a}$$

   **💡 第三步：用法拉第电磁感应定律求 $\varepsilon$**
   对时间 $t$ 求导，注意加负号：
   $$\varepsilon = -\frac{d\Phi_m}{dt} = - \frac{\mu_0 l I_0}{2\pi} \ln\frac{b}{a} \cdot \frac{d(\sin\omega t)}{dt}$$
   $$\varepsilon = - \frac{\mu_0 l I_0 \omega \cos\omega t}{2\pi} \ln\frac{b}{a}$$

### 6. 旋转切割非均匀磁场的动生电动势（2017下/2024上 原题）
**【题目】** 导体棒长 $l$，与通有电流 $I$ 的长直导线共面，绕轴 $O$ 以角速度 $\omega$ 转动。$O$ 点距直导线垂直距离为 $d$ ($d>l$)。当棒转到与导线垂直位置时，求动生电动势。

**【详细解析】**
1. **分步计算过程：**

   **💡 第一步：建立速度微元**
   设棒转到水平垂直于导线时，取距 $O$ 点为 $x$ 的微元 $dx$。
   该微元切割磁感线的线速度大小为 $v = \omega x$。
   此时微元距直导线的距离为 $r = d + x$。

   **💡 第二步：确定磁场与电动势微分**
   该处的磁场 $B = \frac{\mu_0 I}{2\pi(d+x)}$。
   微元动生电动势 $d\varepsilon = vB dx = \omega x \frac{\mu_0 I}{2\pi(d+x)} dx$。

   **💡 第三步：巧用裂项积分法求总电动势**
   对整根棒（$x$ 从 $0$ 到 $l$）积分：
   $$\varepsilon = \int_0^l \frac{\mu_0 I \omega}{2\pi} \frac{x}{d+x} dx = \frac{\mu_0 I \omega}{2\pi} \int_0^l \left(1 - \frac{d}{d+x}\right) dx$$
   分项积分：
   $$\varepsilon = \frac{\mu_0 I \omega}{2\pi} \left[ x - d\ln(d+x) \right]_0^l = \frac{\mu_0 I \omega}{2\pi} \left( l - d\ln\frac{d+l}{d} \right)$$
   *方向：根据右手定则，四指沿速度 $v$ 弯向磁场 $B$ 即可判定高低电势端。*
