## 波动光学板块（干涉与衍射）

### 1. 光栅衍射基础（2017年下期末 第3题）
**【题目】** 波长 400 nm 的平行光垂直照射到透射光栅上，测得第三级亮纹的衍射角为 30°，且第二级亮纹不出现（缺级）。求：（1）光栅常数 $d$；（2）透射光缝的宽度 $a$；（3）屏幕上可呈现的全部亮纹。

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **入射光** | $\lambda = 400\text{ nm}$ | $d \sin\theta = k\lambda$ |
   | **第3级明纹** | $k=3, \theta = 30^\circ$ | 光栅缺级条件：$k = \frac{d}{a} \cdot k'$ |
   | **缺级** | 第 2 级缺级 | 最大级数限制：$k < \frac{d}{\lambda}$ |

2. **分步计算过程：**

   **💡 第一步：求光栅常数 $d$**
   代入光栅方程求第三级极大值：
   $$d \sin 30^\circ = 3\lambda \Rightarrow d \times 0.5 = 3 \times 400\text{ nm}$$
   $$d = 2400\text{ nm} = 2.4\,\mu\text{m}$$

   **💡 第二步：利用缺级条件求缝宽 $a$**
   缺级发生时，光栅的主极大刚好落在了单缝衍射的极小值位置上。
   公式 $k = (d/a) \cdot k'$ 中，第二级缺级说明主极大的第2级（$k=2$）正好对应单缝衍射的第1级暗纹（$k'=1$）：
   $$\frac{d}{a} = \frac{2}{1} = 2 \Rightarrow a = \frac{d}{2} = 1200\text{ nm} = 1.2\,\mu\text{m}$$

   **💡 第三步：求能看到的全部亮纹**
   先计算光栅能产生的理论最高级数：
   $$k_{\text{max}} < \frac{d}{\lambda} = \frac{2400}{400} = 6$$
   所以理论上应有：$k = 0, \pm 1, \pm 2, \pm 3, \pm 4, \pm 5$ 级。
   但由于 $d/a = 2$，所有的偶数级（$k = \pm 2, \pm 4$）均缺级。
   **剔除缺级后，实际呈现亮纹级数：** $k = 0, \pm 1, \pm 3, \pm 5$（共 7 条）。

### 2. 劈尖干涉综合（2019年上/18-19年下 原题再现）
**【题目】** 用 $\lambda = 500\text{ nm}$ 单色光垂直照射空气劈尖。距棱边 $L = 1.56\text{ cm}$ 的 A 处是从棱边算起的第四条暗条纹中心。求：（1）劈尖角 $\theta$；（2）改用 $600\text{ nm}$ 照射，A处是明还是暗？（3）600nm下，从棱边到 A处范围内有几条明纹和暗纹？

**【详细解析】**
1. **公式与参数概览：** 
   | 物理概念 | 参数状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **空气劈尖光程差** | 垂直照射 | $\Delta = 2e + \frac{\lambda}{2}$ (半波损失) |
   | **暗纹条件** | 从 $k=0$ 开始(即棱边) | $\Delta = (2k+1)\frac{\lambda}{2} \Rightarrow 2e = k\lambda$ |
   | **明纹条件** | - | $\Delta = k\lambda \Rightarrow 2e = (k-\frac{1}{2})\lambda$ |

2. **分步计算过程：**

   **💡 第一步：求劈尖角 $\theta$**
   棱边处 $e=0$，对应第1条暗纹（即公式中的 $k=0$）。
   因此，第 4 条暗纹对应的级数是 $k=3$。该处空气厚度 $e$：
   $$2e = 3\lambda_1 \Rightarrow e = \frac{3 \times 500\text{ nm}}{2} = 750\text{ nm}$$
   劈尖角 $\theta \approx \tan\theta = \frac{e}{L} = \frac{750 \times 10^{-9}\text{ m}}{1.56 \times 10^{-2}\text{ m}} \approx 4.81 \times 10^{-5}\text{ rad}$

   **💡 第二步：换用 600nm 判定 A 处明暗**
   在 A 处，空气层厚度仍为 $e = 750\text{ nm}$，改用 $\lambda_2 = 600\text{ nm}$：
   计算光程差包含半波损失：
   $$\Delta = 2e + \frac{\lambda_2}{2} = 2(750) + 300 = 1500 + 300 = 1800\text{ nm}$$
   看它是波长的几倍：$\frac{\Delta}{\lambda_2} = \frac{1800}{600} = 3$（整数倍）。
   结论：满足干涉相长条件，**A 处是明条纹**。

   **💡 第三步：清点条纹数量**
   在 $600\text{ nm}$ 下，范围是从 $e=0$ 到 $e=750\text{ nm}$。
   - **求暗纹：** 满足 $2e = k\lambda_2 = k(600) \Rightarrow e = k \times 300\text{ nm}$。
     $k=0 (e=0)$， $k=1 (e=300)$， $k=2 (e=600)$。**共 3 条暗纹**。
   - **求明纹：** 满足 $2e = (k-\frac{1}{2})\lambda_2 = (k-0.5) \times 600 \Rightarrow e = (k-0.5) \times 300\text{ nm}$。
     $k=1 (e=150)$， $k=2 (e=450)$， $k=3 (e=750)$。**共 3 条明纹**。

### 3. 杨氏双缝干涉白光模糊（2016-17年下 第78题）
**【题目】** 杨氏双缝，波长 $700\text{ nm}$ 光的1级明纹间距 $1.4\text{ cm}$。求 (1) 同侧 $400\text{ nm}$ 和 $600\text{ nm}$ 第1级明纹距离；(2) 取 $\Delta\lambda = 100\text{ nm}$，$\bar{\lambda} = 490\text{ nm}$ 的蓝绿光，条纹从第几级开始模糊？

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 描述 | 公式原型 |
   | :--- | :--- | :--- |
   | **明纹坐标** | 距中央明纹距离 | $y = \frac{D}{d} k\lambda$ |
   | **干涉重叠(模糊)** | 光谱宽度覆盖条纹间距 | $k \approx \frac{\bar{\lambda}}{\Delta\lambda}$ |

2. **分步计算过程：**

   **💡 第一步：提取仪器常数 $\frac{D}{d}$**
   题目给的是“两侧1级明纹距离”，即 $2y_1 = 1.4\text{ cm} \Rightarrow y_1 = 0.7\text{ cm} = 0.007\text{ m}$。
   代入公式 $y_1 = \frac{D}{d}\lambda \Rightarrow \frac{D}{d} = \frac{0.007}{700 \times 10^{-9}} = 10^4$。

   **💡 第二步：计算明纹距离**
   $400\text{ nm}$ 和 $600\text{ nm}$ 的1级（$k=1$）明纹距离差：
   $$\Delta y = y_{600} - y_{400} = \frac{D}{d}(1)(\lambda_2 - \lambda_1)$$
   $$\Delta y = 10^4 \times (600 - 400) \times 10^{-9} = 2 \times 10^{-3}\text{ m} = 2\text{ mm}$$

   **💡 第三步：计算条纹模糊级数**
   白光包含多波长，高阶条纹的彩色带会随级数增大而变宽，直至相邻级重叠导致模糊。
   重叠级数估算公式：$k \ge \frac{\bar{\lambda}}{\Delta\lambda}$。
   $$k = \frac{490}{100} = 4.9$$
   因为级数为整数，所以**从第 5 级开始变得模糊不清**。

### 4. 双波长光栅衍射重叠（2017-18年下 第73题）
**【题目】** $\lambda_1$（红）与 $\lambda_2$（紫）入射每毫米300条的光栅。在 $\theta = 24^\circ$ ($\sin 24^\circ=0.4068$) 处两谱线重合。求 (1)两波长；(2)重合的红光正级数；(3)单独呈现紫光的正级数。

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **光栅常数** | 1 mm有300条缝 | $d = \frac{10^{-3}\text{ m}}{300}$ |
   | **重叠条件** | 同一个角度 $\theta$ 处 | $d\sin\theta = k_1\lambda_1 = k_2\lambda_2$ |

2. **分步计算过程：**

   **💡 第一步：定波长**
   先算 $d\sin 24^\circ$ 对应的总长度：
   $$d = \frac{1}{300}\text{ mm} = \frac{10}{3} \times 10^{-6}\text{ m}$$
   $$L = d\sin 24^\circ = \frac{10}{3} \times 10^{-6} \times 0.4068 = 1.356 \times 10^{-6}\text{ m} = 1356\text{ nm}$$
   必须满足 $k_1\lambda_1 = k_2\lambda_2 = 1356\text{ nm}$，且知可见光红光($620\sim 760\text{nm}$)，紫光($400\sim 450\text{nm}$)。
   尝试整数级 $k$：
   当 $k_1 = 2$ 时，$\lambda_1 = \frac{1356}{2} = 678\text{ nm}$（符合红光）。
   当 $k_2 = 3$ 时，$\lambda_2 = \frac{1356}{3} = 452\text{ nm}$（符合紫光）。

   **💡 第二步：找出屏幕上重合的红光正级数**
   波长比为 $\lambda_1 : \lambda_2 = 678 : 452 = 3 : 2$。
   重合条件为 $k_1 \times 3 = k_2 \times 2$，即当 $k_1$ 为 2的倍数时重合（$k_1=2, 4, 6...$）。
   校验最大极值限制：$k_{\text{1max}} \le \frac{d}{\lambda_1} = \frac{3333}{678} \approx 4.9$。
   因此，红光只有 $1, 2, 3, 4$ 级。**重合的红光正级数为：$k_1 = 2, 4$**。

   **💡 第三步：找出单独呈现紫光的级数**
   紫光极值限制：$k_{\text{2max}} \le \frac{d}{\lambda_2} = \frac{3333}{452} \approx 7.3$。
   紫光存在：$1, 2, 3, 4, 5, 6, 7$ 级。
   其中与红光重合的紫光级数为 $k_2 = 3$（对应 $k_1=2$）和 $k_2 = 6$（对应 $k_1=4$）。
   剔除重合项，**单独呈现的紫光正级数为：$1, 2, 4, 5, 7$**。

## 几何光学板块（眼睛与透镜成像）

### 5. 简约眼焦度与近视度数（2017年下 第4题）
**【题目】** 简约眼角膜曲率半径 $r=4.7\text{ mm}$，眼内折射率 $n=1.33$，眼轴长 $L=20\text{ mm}$。(1) 焦度？(2) 使无穷远成像于视网膜，配戴多少度眼镜？

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 描述 | 公式原型 |
   | :--- | :--- | :--- |
   | **球面焦度 $\Phi$** | $r=0.0047\text{ m}, n_0=1$ | $\Phi = \frac{n - n_0}{r}$ |
   | **组合焦度** | 佩戴薄透镜紧贴角膜 | $\Phi_{\text{总}} = \Phi_{\text{眼}} + \Phi_{\text{镜}}$ |
   | **成像要求** | 物距 $u \rightarrow -\infty$，像距 $v = 20\text{ mm}$ | $\frac{n}{v} - \frac{1}{u} = \Phi_{\text{总}}$ |

2. **分步计算过程：**

   **💡 第一步：计算简约眼自身的焦度**
   $$\Phi = \frac{1.33 - 1}{0.0047} = \frac{0.33}{0.0047} \approx 70.21\text{ D} (屈光度)$$

   **💡 第二步：计算完全矫正所需总焦度**
   要使来自$-\infty$的光恰好汇聚在视网膜（$L = 0.02\text{ m}$）上：
   $$\frac{1.33}{0.02} - \frac{1}{-\infty} = \Phi_{\text{总}} \Rightarrow \Phi_{\text{总}} = 66.50\text{ D}$$

   **💡 第三步：求配镜度数**
   眼镜需要提供的额外焦度为：
   $$\Phi_{\text{镜}} = \Phi_{\text{总}} - \Phi = 66.50 - 70.21 = -3.71\text{ D}$$
   **结论：** 需配戴焦度为 $-3.71\text{ D}$ 的凹透镜（即大约 371度的近视镜）。

### 6. 简约眼与屈光不正定性（2022年下 第27题）
**【题目】** 简约眼无原图，采用生理光学标准模型眼假定：$r=5\text{ mm}, n=1.33, L=20\text{ mm}$。(1)焦度；(2)像方焦距；(3)远点；(4)何种屈光不正；(5)配镜。

**【详细解析】**
1. **分步计算过程：**

   **💡 (1) 焦度**
   $$\Phi = \frac{1.33 - 1}{0.005\text{ m}} = 66\text{ D}$$

   **💡 (2) 像方焦距 $f'$**
   $$f' = \frac{n}{\Phi} = \frac{1.33}{66} \approx 0.02015\text{ m} = 20.15\text{ mm}$$

   **💡 (3) 远点位置 $l_r$**
   未戴眼镜时，看远点成像在视网膜上（像距 $v = 20\text{ mm} = 0.02\text{ m}$）。
   $$\frac{n}{v} - \frac{1}{l_r} = \Phi \Rightarrow \frac{1.33}{0.02} - \frac{1}{l_r} = 66 \Rightarrow 66.5 - \frac{1}{l_r} = 66$$
   $$\frac{1}{l_r} = 0.5 \Rightarrow l_r = 2\text{ m}$$ (因未用虚实符号，传统眼科中远点在眼前为负。此处代数距离为 $2\text{m}$，实际上是指位于眼后 2m 处的虚物点)。

   **💡 (4) 何种屈光不正？**
   因为像方焦距 ($20.15\text{ mm}$) > 眼轴长 ($20\text{ mm}$)，光线聚焦在视网膜之后，属于**远视眼**。

   **💡 (5) 配镜屈光度**
   使无穷远像落在视网膜所需的总焦度 $\Phi_{\text{需}} = \frac{1.33}{0.02} = 66.5\text{ D}$。
   眼镜焦度 $\Phi_{\text{镜}} = 66.5 - 66 = +0.5\text{ D}$（配戴 50度凸透镜）。

### 7. 单球面连续折射（2020年下 第16题）
**【题目】** 玻璃球半径 $10\text{ cm}, n=1.5$。点光源放球前 $40\text{ cm}$，求最终成像位置。

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 单球面折射公式约定 | 公式原型 |
   | :--- | :--- | :--- |
   | **折射成像** | 光线方向由左至右 | $\frac{n_2}{v} - \frac{n_1}{u} = \frac{n_2-n_1}{r}$ |

2. **分步计算过程：**

   **💡 第一步：光线经过球前表面（第一次折射）**
   $n_1=1, n_2=1.5, r_1=+10\text{ cm}, u_1=-40\text{ cm}$（光在前，为实物）。
   $$\frac{1.5}{v_1} - \frac{1}{-40} = \frac{1.5 - 1}{10} \Rightarrow \frac{1.5}{v_1} + \frac{1}{40} = \frac{2}{40}$$
   $$\frac{1.5}{v_1} = \frac{1}{40} \Rightarrow v_1 = +60\text{ cm}$$
   （第一像在球前表面右侧 60cm 处）。

   **💡 第二步：光线经过球后表面（第二次折射）**
   球直径为 20cm。光线趋向于聚焦在后方60cm处，但在20cm处遇到后表面。
   对后表面而言，$I_1$ 是位于其右侧的**虚物**，物距 $u_2 = +(60 - 20) = +40\text{ cm}$。
   此时光由玻璃进入空气：$n_2=1.5, n_3=1, r_2=-10\text{ cm}$。
   $$\frac{1}{v_2} - \frac{1.5}{+40} = \frac{1 - 1.5}{-10} \Rightarrow \frac{1}{v_2} - \frac{1.5}{40} = \frac{0.5}{10} = \frac{2}{40}$$
   $$\frac{1}{v_2} = \frac{3.5}{40} \Rightarrow v_2 = \frac{40}{3.5} \approx 11.43\text{ cm}$$
   **结论：** 最终成像在玻璃球后表面右侧 $11.43\text{ cm}$ 处。

### 8. 双凸厚透镜成像（2023年下 第35题）
**【题目】** 对称双凸厚透镜，厚 $d=5\text{cm}, r_1=5\text{cm}, r_2=-5\text{cm}, n=1.5$。光源在前表面外 20cm处，求像离透镜后表面距离。

**【详细解析】**
1. **分步计算过程：**

   **💡 第一步：前表面折射**
   $u_1 = -20\text{ cm}$。公式 $\frac{1.5}{v_1} - \frac{1}{-20} = \frac{1.5-1}{5} = 0.1$。
   $$\frac{1.5}{v_1} + 0.05 = 0.1 \Rightarrow \frac{1.5}{v_1} = 0.05 \Rightarrow v_1 = +30\text{ cm}$$
   （像在第一面后方 30cm）。

   **💡 第二步：后表面折射**
   透镜厚 $5\text{ cm}$，对于后表面，$I_1$ 为虚物，距后表面 $u_2 = +(30-5) = +25\text{ cm}$。
   后表面 $r_2 = -5\text{ cm}$，光从玻璃出射至空气：
   $$\frac{1}{v_2} - \frac{1.5}{25} = \frac{1-1.5}{-5} = 0.1$$
   $$\frac{1}{v_2} - 0.06 = 0.1 \Rightarrow \frac{1}{v_2} = 0.16 \Rightarrow v_2 = \frac{1}{0.16} = 6.25\text{ cm}$$
   **结论：** 成像在透镜后表面之后 $6.25\text{ cm}$ 处。

### 9. 远视眼配镜实际应用（2025年上 第51题）
**【题目】** 正常人明视距离 25cm。一远视眼患者戴 2D 眼镜时要在眼前 40cm处看书。求能和正常人一样看书需配多少度？

**【详细解析】**
1. **公式与参数概览：** 
   | 物理原理 | 逻辑关联 | 公式原型 |
   | :--- | :--- | :--- |
   | **薄透镜成像** | 戴眼镜看书，书为物，像在其眼球**实际近点** | $\frac{1}{v} - \frac{1}{u} = \Phi$ |
   | **符号系统** | 眼前物体为负值 | $u = -0.4\text{m}$，$\Phi=2\text{D}$ |

2. **分步计算过程：**

   **💡 第一步：反推患者的实际近点距离**
   患者戴 $2\text{D}$ 眼镜看 $40\text{ cm}$ ($u_1 = -0.4\text{ m}$) 的书，成像到他的近点 $v$：
   $$\frac{1}{v} - \frac{1}{-0.4} = 2 \Rightarrow \frac{1}{v} + 2.5 = 2 \Rightarrow \frac{1}{v} = -0.5$$
   $$v = -2\text{ m}$$
   说明该患者裸眼只能看清位于眼前 2 米远处的物体。

   **💡 第二步：计算目标配镜度数**
   现在要让他像正常人一样在 $25\text{ cm}$ ($u_2 = -0.25\text{ m}$) 处看书。
   这副新眼镜必须把位于 -0.25m 处的物，成像在他能看清的近点 -2m 处：
   $$\Phi_{\text{新}} = \frac{1}{v} - \frac{1}{u_2} = \frac{1}{-2} - \frac{1}{-0.25} = -0.5 + 4 = 3.5\text{ D}$$
   **结论：** 此人应配戴 350度（$3.5\text{ D}$）的凸透镜眼镜。
