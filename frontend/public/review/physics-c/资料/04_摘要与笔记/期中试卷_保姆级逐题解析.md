### 1. 某质点作直线运动的运动学方程为 $x=3t-5t^3+6$ (SI)，则该质点作
(A) 匀加速直线运动，加速度沿 $x$ 轴正方向
(B) 匀加速直线运动，加速度沿 $x$ 轴负方向
(C) 变加速直线运动，加速度沿 $x$ 轴正方向
(D) 变加速直线运动，加速度沿 $x$ 轴负方向

**【正确答案】** D

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **运动学方程** | $x = 3t - 5t^3 + 6$ | - |
   | **速度** | 待求 | $v = \frac{dx}{dt}$ |
   | **加速度** | 待求 | $a = \frac{dv}{dt}$ |

2. **分步计算过程：**

   **💡 第一步：求速度与加速度方程**
   将运动学方程代入求导：
   $$v = \frac{d(3t - 5t^3 + 6)}{dt} = 3 - 15t^2$$
   $$a = \frac{d(3 - 15t^2)}{dt} = -30t$$

   **💡 第二步：分析物理意义**
   - 因为加速度 $a = -30t$ 中含有时间变量 $t$，说明加速度随时间改变，故为**变加速运动**。
   - 因为时间 $t \ge 0$，所以 $a \le 0$，即加速度的方向始终沿 $x$ 轴的负方向。

3. **结论：** 
   该质点作变加速直线运动，加速度沿 $x$ 轴负方向，选 D。
**🏥 医学物理点拨：** 就像在分析心动周期中血液流速的变化时，其加速度是随时间周期性改变的，属于变加速流体运动，切忌套用简单的匀加速公式。

### 2. 一质点作匀速率圆周运动时，
(A) 它的动量不变，对圆心的角动量也不变
(B) 它的动量不变，对圆心的角动量不断改变
(C) 它的动量不断改变，对圆心的角动量不变
(D) 它的动量不断改变，对圆心的角动量也不断改变

**【正确答案】** C

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **运动状态** | 匀速率圆周运动 | 速率 $v$ 保持不变 |
   | **动量** | 待分析 | $\vec{p} = m\vec{v}$ |
   | **角动量** | 待分析 | $\vec{L} = \vec{r} \times \vec{p}$ |

2. **分步逻辑分析：**

   **💡 第一步：分析动量变化**
   匀速率圆周运动中，速率 $v$ 不变，但速度方向 $\vec{v}$ 时刻在沿着圆周的切线方向改变。动量 $\vec{p}$ 是矢量，方向改变意味着动量**不断改变**。

   **💡 第二步：分析角动量变化**
   - **大小：** $L = mvr \sin(90^\circ) = mvr$。由于 $m$、$v$、$r$ 皆为常数，故大小不变。
   - **方向：** 由右手定则判定（$\vec{r}$ 叉乘 $\vec{v}$），始终垂直于圆周运动所在的平面，方向保持不变。
   - 故角动量矢量**保持不变**。

3. **结论：** 
   动量改变，角动量不变，选 C。

### 3. 质量为 $m$ 的小孩站在半径为 $R$ 的水平平台边缘上... 平台相对地面旋转的角速度和旋转方向分别为
(A) $\frac{mR^2}{J}\left(\frac{v}{R}\right)$，顺时针
(B) $\frac{mR^2}{J}\left(\frac{v}{R}\right)$，逆时针
(C) $\frac{mR^2}{J+mR^2}\left(\frac{v}{R}\right)$，顺时针
(D) $\frac{mR^2}{J+mR^2}\left(\frac{v}{R}\right)$，逆时针

**【正确答案】** A

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **守恒定律** | 系统不受外力矩 | $\sum \vec{L}_{\text{初}} = \sum \vec{L}_{\text{末}}$ |
   | **小孩角动量** | 速率 $v$ (逆时针) | $L_{\text{孩}} = mvr$ |
   | **平台角动量** | 转动惯量 $J$ | $L_{\text{台}} = J\omega$ |

2. **分步计算过程：**

   **💡 第一步：代入初始与最终状态**
   规定逆时针为正方向。初始状态均静止，系统总初角动量 $L_{\text{初}} = 0$。
   小孩相对地面的角动量为 $L_{\text{孩}} = m v R$。
   平台相对地面的角动量为 $L_{\text{台}} = J \omega$。
   代入角动量守恒方程：
   $$0 = m v R + J \omega$$

   **💡 第二步：解方程求平台角速度**
   移项解得：
   $$\omega = -\frac{m v R}{J}$$
   为贴合选项形式，将式子改写：
   $$\omega = -\frac{m R^2}{J} \left( \frac{v}{R} \right)$$
   负号表示其方向与小孩走动方向相反，即**顺时针**方向。

3. **结论：** 
   选 A。

### 4. 把一块不锈钢放在静止的深水中，它所受到的应力是
(A) 拉应力  (B) 压应力  (C) 切应力  (D) 三者都有

**【正确答案】** B

**【详细解析】**
1. **公式与参数概览：** 
   | 物理概念 | 解释 |
   | :--- | :--- |
   | **流体静力学** | 处于静止状态的流体内部，只能承受并传递**压应力**，无法承受拉应力和切应力。 |

2. **分步逻辑分析：**

   **💡 第一步：场景分析**
   深水中的不锈钢块被周围的液体包围，水分子对不锈钢表面的作用力处处垂直于其表面并指向内部。在固体力学中，这称为“体压应力”。

3. **结论：** 
   只有压应力，故选 B。
**🏥 医学物理点拨：** 潜水病或高压氧舱治疗中，人体所承受的均是流体带来的纯压应力。

### 5. 两个质点作振幅、周期相同的简谐振动... 第二个质点正在最大正位移处，则第二个质点的振动方程为
(A) $x_2 = A\cos(\omega t + \alpha + \frac{\pi}{2})$
(B) $x_2 = A\cos(\omega t + \alpha + \pi)$
(C) $x_2 = A\cos(\omega t + \alpha - \pi)$
(D) $x_2 = A\cos(\omega t + \alpha - \frac{\pi}{2})$

**【正确答案】** D

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **质点 1** | $x_1 = A\cos(\omega t + \alpha)$ | 质点 1 回到平衡位置 ($x_1=0, v_1<0$) |
   | **质点 2** | 待求 | 质点 2 在最大正位移处 ($x_2=A$) |

2. **分步计算过程：**

   **💡 第一步：利用旋转矢量法确定质点1的当前相位**
   第一质点“从相对平衡位置的正位移处回到平衡位置”：意味着位移 $x_1 = 0$ 且向负方向运动（速度 $v_1 < 0$）。
   代入方程：$A\cos(\Phi_1) = 0$ 且 $-\omega A\sin(\Phi_1) < 0$。
   解得当前相位 $\Phi_1 = \frac{\pi}{2} + 2k\pi$。此时 $\omega t + \alpha = \frac{\pi}{2}$。

   **💡 第二步：确定质点2的当前相位与方程**
   第二质点“正在最大正位移处”：即位移 $x_2 = A$。
   代入方程：$A\cos(\Phi_2) = A \Rightarrow \cos(\Phi_2) = 1$。
   解得当前相位 $\Phi_2 = 0 + 2k\pi$。
   两者的相位差 $\Delta \Phi = \Phi_2 - \Phi_1 = 0 - \frac{\pi}{2} = -\frac{\pi}{2}$。

3. **结论：** 
   第二个质点的振动方程比第一个落后 $\frac{\pi}{2}$，即 $x_2 = A\cos\left((\omega t + \alpha) - \frac{\pi}{2}\right)$。选 D。

### 6. 质点作简谐振动，其速度最大值为 $v_m = 3\times 10^{-2}\text{ m/s}$，振幅 $A = 2\times 10^{-2}\text{ m}$，若从速度为正的最大值开始计时...
(A) (1)(4)  (B) (2)(3)  (C) (1)(2)  (D) (3)(4)

**【正确答案】** B

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据 | 公式原型 |
   | :--- | :--- | :--- |
   | **最大速度** | $v_m = 3\times 10^{-2}\text{ m/s}$ | $v_m = \omega A$ |
   | **最大加速度** | 待求 | $a_m = \omega^2 A$ |
   | **周期** | 待求 | $T = \frac{2\pi}{\omega}$ |
   | **振幅** | $A = 2\times 10^{-2}\text{ m}$ | 振动方程: $x = A\cos(\omega t + \varphi)$ |

2. **分步计算过程：**

   **💡 第一步：求角频率 $\omega$ 与周期 $T$**
   $$\omega = \frac{v_m}{A} = \frac{3\times 10^{-2}}{2\times 10^{-2}} = 1.5\text{ rad/s}$$
   $$T = \frac{2\pi}{\omega} = \frac{2\pi}{1.5} = \frac{4\pi}{3}\text{ s}$$
   *结论：命题 (2) 的前半部分周期正确。*

   **💡 第二步：求最大加速度 $a_m$**
   $$a_m = \omega^2 A = (1.5)^2 \times (2\times 10^{-2}) = 4.5 \times 10^{-2}\text{ m/s}^2$$
   *结论：命题 (3) 正确。*

   **💡 第三步：求初相 $\varphi$ (初始状态分析)**
   - 计时起点（$t=0$）时，速度达到正的最大值（$v = +v_m$）。
   - 简谐振动中速度达到最大时，质点必然在平衡位置（$x = 0$）。
   - 代入初始条件方程，此时 $x$ 取 $0$，$v$ 取正值：
     $$x(0) = A\cos(\varphi) = 0$$
     $$v(0) = -\omega A\sin(\varphi) = \omega A > 0 \Rightarrow \sin(\varphi) = -1$$
   - 解得初相位 $\varphi = -\frac{\pi}{2}$。

3. **结论：** 
   结合上述计算，(2) 和 (3) 是正确的组合，故选 B。

### 7. 一平面简谐波在弹性媒质中传播时，某一时刻在传播方向上媒质中某质元在负的最大位移处，则它的能量是
(A) 动能为零，势能最大  (B) 动能为零，势能为零
(C) 动能最大，势能最大  (D) 动能最大，势能为零

**【正确答案】** B

**【详细解析】**
1. **公式与参数概览：** 
   | 物理概念 | 特性 |
   | :--- | :--- |
   | **机械波能量** | 在波动传播中，质元的动能与势能是**同相变化**的，即同时达到最大，同时达到最小。 |
   | **振动动能** | $dE_k = \frac{1}{2}dm \cdot v^2$ |

2. **分步逻辑分析：**

   **💡 第一步：分析动能**
   当质元处于负的最大位移处（波谷）时，该质元瞬间速度为零（运动到折返点），因此**动能为零**。

   **💡 第二步：分析势能**
   弹性势能与介质形变率成正比。波形曲线在波峰和波谷处的斜率为零，即相对形变为零，因此**弹性势能也为零**。

3. **结论：** 
   动能与势能同时为零，选 B。

### 8. 两列声波振幅相同，角频率之比为 $\omega_1 : \omega_2 = 1 : 2$，声强和声强级关系为
(A) $I_2 = 4I_1, L_2 = L_1 + 6$   (B) $I_2 = 4I_1, L_2 = L_1 + 12$
(C) $I_2 = 2I_1, L_2 = L_1 + 3$   (D) $I_2 = 2I_1, L_2 = L_1 + 6$

**【正确答案】** A

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **声强 $I$** | $A_1 = A_2, \omega_1:\omega_2 = 1:2$ | $I = \frac{1}{2}\rho u \omega^2 A^2$ |
   | **声强级 $L$** | 待求 | $L = 10 \lg \left(\frac{I}{I_0}\right)$ (dB) |

2. **分步计算过程：**

   **💡 第一步：求声强关系**
   同介质中传播（$\rho, u$ 相同），且振幅 $A$ 相同，则声强 $I \propto \omega^2$。
   $$\frac{I_1}{I_2} = \left(\frac{\omega_1}{\omega_2}\right)^2 = \left(\frac{1}{2}\right)^2 = \frac{1}{4}$$
   得到 $I_2 = 4I_1$。

   **💡 第二步：求声强级关系**
   $$L_2 = 10 \lg \left(\frac{I_2}{I_0}\right) = 10 \lg \left(\frac{4I_1}{I_0}\right)$$
   展开对数：
   $$L_2 = 10 \left[ \lg 4 + \lg \left(\frac{I_1}{I_0}\right) \right] = 10 \lg 4 + L_1$$
   因为 $\lg 4 \approx 0.602$，所以 $L_2 \approx 6 + L_1\text{ dB}$。

3. **结论：** 
   选 A。
**🏥 医学物理点拨：** 超声波诊断中（如 B超），探头频率提高一倍，组织的声能吸收和初始声强变化显著，这就是为何浅表组织用高频探头、深部组织用低频探头的原因。

### 9. 两瓶不同种类的理想气体，它们的温度和压强都相同，但体积不同... 
**【正确答案】** C

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **状态方程** | $T, p$ 相同 | $p = n k T$ |
   | **单位体积动能** | 待求 | $\frac{E_k}{V} = n \cdot \frac{3}{2} k T$ |
   | **单位体积质量** | 气体种类不同 | $\rho = n \cdot m_{分子}$ |

2. **分步逻辑分析：**

   **💡 第一步：分析单位体积分子数 $n$**
   由 $n = \frac{p}{kT}$，既然两气体的压强 $p$ 和温度 $T$ 都相同，则 $n$ 必然相同。

   **💡 第二步：分析单位体积总平动动能 $\frac{E_k}{V}$ 与 密度 $\rho$**
   - $\frac{E_k}{V} = n \cdot \frac{3}{2}kT = \frac{3}{2}p$。因为压强 $p$ 相同，所以该项相同。
   - $\rho = n \cdot m_{分子}$。由于是“不同种类”的理想气体，分子质量 $m_{分子}$ 不同，因此 $\rho$ 不同。

3. **结论：** 
   $n$ 相同，$E_k/V$ 相同，$\rho$ 不同。选 C。

### 10. 氢气当温度不变而压强增大一倍时，平均碰撞频率 $Z$ 和平均自由程 $\lambda$ 的变化情况是
**【正确答案】** D

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 变化情况 | 公式原型 |
   | :--- | :--- | :--- |
   | **状态参量** | $T$ 不变，$p \rightarrow 2p$ | $p = n k T$ |
   | **平均自由程** | 待求 | $\lambda = \frac{1}{\sqrt{2} \pi d^2 n}$ |
   | **平均碰撞频率** | 待求 | $Z = \sqrt{2} \pi d^2 \bar{v} n$ |

2. **分步计算过程：**

   **💡 第一步：分析分子数密度 $n$ 和 平均速率 $\bar{v}$**
   - 由 $n = \frac{p}{kT}$ 可知，压强变为2倍，$n$ 也随之增大一倍（$n \rightarrow 2n$）。
   - 温度 $T$ 不变，使得分子平均速率 $\bar{v}$ 保持不变。

   **💡 第二步：代入求解目标变量**
   - 自由程公式分母上的 $n$ 变为 2倍，则 $\lambda \rightarrow \frac{1}{2}\lambda$（减为原来的一半）。
   - 碰撞频率公式中的 $n$ 变为 2倍，$\bar{v}$ 不变，则 $Z \rightarrow 2Z$（增大一倍）。

3. **结论：** 
   $Z$ 增大一倍，$\lambda$ 减为一半。选 D。

### 12. 静电场的环路定理 $\oint_l \vec{E} \cdot d\vec{l} = 0$，说明了静电场的哪些性质
**【正确答案】** C (即包含2、4的组合)

**【详细解析】**
1. **定理剖析：** 
   $\oint_l \vec{E} \cdot d\vec{l} = 0$ 意味着在一个任意闭合路径上，电场力做功恒为零。

2. **分步逻辑分析：**

   **💡 第一步：推导直接性质**
   - 做功与路径无关，是**保守力**的根本特征。说明“库仑力（静电力）是保守力”（性质2）。
   - 由于力场是保守力，因而构成的物理场就是**保守场**（性质4）。

   **💡 第二步：排除无关性质**
   (1) 电场线不闭合是几何表象，非核心场性质；(3) 有源场是由高斯定理（$\oint \vec{E}\cdot d\vec{S} = \frac{q}{\epsilon_0}$）说明的。

3. **结论：** 
   体现了(2)和(4)，选 C。

### 13. 电偶极子激发的电场中，距中心 $r$ 处场强大小和电势分别与 ___ 成正比
**【正确答案】** D

**【详细解析】**
1. **公式与参数概览：** 
   | 物理量 | 单一点电荷模型 | 电偶极子模型 (远区 $r \gg l$) |
   | :--- | :--- | :--- |
   | **电势 $V$** | $V \propto \frac{1}{r}$ | $V = \frac{p \cos\theta}{4\pi\epsilon_0 r^2} \propto r^{-2}$ (对应 3) |

**【题目】** 一个力 $\vec{F} = (2+3t)\vec{i}$ 作用在 $m=1.0\text{ kg}$ 的质点上，从静止开始运动。求 $0 \sim 2\text{ s}$ 内的冲量大小 $I$ 和力做的功 $W$。

   | :--- | :--- | :--- |
   | **冲量** | $t: 0\sim 2\text{s}$ | $\vec{I} = \int_{t_1}^{t_2} \vec{F} dt$ |
   | **做功** | 初速 $v_1=0$ | $\vec{I} = m\vec{v}_2 - m\vec{v}_1$, $W = \Delta E_k$ |

2. **分步计算过程：**

   **💡 第一步：求冲量 $I$**
   $$\vec{I} = \int_{0}^{2} (2+3t)\vec{i} dt = \left[ 2t + \frac{3}{2}t^2 \right]_{0}^{2} \vec{i}$$
   $$\vec{I} = \left( 4 + 6 \right)\vec{i} = 10\vec{i} \text{ N}\cdot\text{s}$$
   大小为 $10\text{ N}\cdot\text{s}$。

   **💡 第二步：求做功 $W$**
   动量定理得末速度：$\vec{v}_2 = \frac{\vec{I}}{m} = \frac{10\vec{i}}{1.0} = 10\vec{i} \text{ m/s}$。
   动能定理得做功：$W = \frac{1}{2} \times 1.0 \times (10)^2 - 0 = 50\text{ J}$。

### 1. 刚体定轴转动与摩擦力矩
**【题目内容】** 一细杆长 $l$ 质量 $m$ ，在摩擦系数为 $\mu$ 的水平桌面上绕一端转动。初始角速度为 $\omega_0$。求摩擦力矩、任意时刻的角速度及停止前转过的角度。

**【标准解答】**
1. **公式与参数概览：** 
   | 物理量 | 已知数据/状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **刚体转动定律** | $J = \frac{1}{3} m l^2$ | $M = J \alpha$ |
   | **运动学公式** | 匀减速至 $\omega_t = 0$ | $\omega(t) = \omega_0 + \alpha t$, $\omega_t^2 - \omega_0^2 = 2 \alpha \theta$ |

2. **分步计算过程：**

   **💡 (1) 微元法求摩擦力矩与角加速度**
   在杆上距转轴 $r$ 处取微元 $dm = \frac{m}{l} dr$。其受到的滑动摩擦力 $dF_f = \mu \frac{m g}{l} dr$。
   积分求总阻力矩：
   $$M_f = \int_{0}^{l} \frac{\mu m g}{l} r dr = \frac{\mu m g}{l} \left[ \frac{1}{2}r^2 \right]_{0}^{l} = \frac{1}{2} \mu m g l$$
   根据 $M = J \alpha$，摩擦力矩充当阻力矩：
   $$-\frac{1}{2}\mu m g l = \left( \frac{1}{3} m l^2 \right) \alpha \Rightarrow \alpha = -\frac{3 \mu g}{2 l}$$

   **💡 (2) 任意时刻的角速度**
   杆作匀减速转动，直接代入公式：
   $$\omega(t) = \omega_0 - \frac{3 \mu g}{2 l} t$$

   **💡 (3) 停止前转过的角度**
   套用无时间相关的匀变速公式：
   $$0 - \omega_0^2 = 2 \left( -\frac{3 \mu g}{2 l} \right) \theta \Rightarrow \theta = \frac{\omega_0^2 l}{3 \mu g}$$

   | **周期 $T$** | $\frac{2}{10} = 0.2\text{ s}$ | $T = \frac{\lambda}{u}$ |
   | **角频率 $\omega$** | $10\pi\text{ rad/s}$ | $\omega = \frac{2\pi}{T}$ |
   | **波数 $k$** | $\pi\text{ m}^{-1}$ | $k = \frac{2\pi}{\lambda}$ |

2. **分步逻辑分析：**

   **💡 (1) 波函数**
   沿正向传播标准形式 $y(x,t) = A\cos(\omega t - kx + \varphi)$。结合初始平衡点且向上振动的假设，$\varphi=-\frac{\pi}{2}$：
   $$y(x,t) = A\cos(10\pi t - \pi x - \frac{\pi}{2}) = A\sin(10\pi t - \pi x)$$

   **💡 (2) 回到平衡位置所需最短时间**
   假若点处波峰，回到平衡位置需 $\frac{T}{4}$：$t = \frac{0.2}{4} = 0.05\text{ s}$。

### 4. 热力学循环（布雷顿循环）
**【题目内容】** AB等压，BC绝热，CD等压，DA绝热。B温度 $T_2$，C温度 $T_3$。求效率，并回答是否为卡诺循环。

**【标准解答】**
1. **公式与参数概览：** 
   | 物理概念 | 参数状态 | 公式原型 |
   | :--- | :--- | :--- |
   | **热机效率** | AB吸热, CD放热 | $\eta = 1 - \frac{\|Q_{\text{放}}\|}{Q_{\text{吸}}} = 1 - \frac{T_C - T_D}{T_B - T_A}$ |
   | **绝热方程** | BC, DA 绝热过程 | $\frac{T}{P^{\frac{\gamma-1}{\gamma}}} = \text{Const}$ |

2. **分步计算过程：**

   **💡 第一步：建立各点温度联系**
   BC和DA处于相同两条等压线之间：
   $\frac{T_B}{T_C} = \left(\frac{P_1}{P_2}\right)^{\frac{\gamma-1}{\gamma}} = \frac{T_A}{T_D} \Rightarrow \frac{T_A}{T_B} = \frac{T_D}{T_C}$

   **💡 第二步：效率化简与计算**
   $$\eta = 1 - \frac{T_C (1 - T_D/T_C)}{T_B (1 - T_A/T_B)} = 1 - \frac{T_C}{T_B}$$
   根据已知 $T_B = T_2, T_C = T_3$ 代入，得 $\eta = 1 - \frac{T_3}{T_2}$。

   **💡 第三步：辨析循环种类**
   并非卡诺循环。卡诺循环由等温+绝热组成，而此循环是等压+绝热（布雷顿循环）。

### 5. 电磁学（平行双导线电容）
**【题目内容】** 两平行无限长直导线，半径 $a$，相距 $d$($d \gg a$)。求单位长度电容。

**【标准解答】**
1. **公式与参数概览：** 
   | 物理量 | 描述 | 公式原型 |
   | :--- | :--- | :--- |
   | **场强叠加** | 一正一负带电 $+\lambda, -\lambda$ | $E = \frac{\lambda}{2\pi\epsilon_0 x} + \frac{\lambda}{2\pi\epsilon_0 (d-x)}$ |
   | **电势差 $U$** | 积分求电场做功 | $U = \int_{a}^{d-a} E dx$ |
   | **电容 $C$** | 单位长度电量为 $\lambda$ | $C = \frac{\lambda}{U}$ |

2. **分步计算过程：**

   **💡 第一步：积分求电势差**
   $$U = \frac{\lambda}{2\pi\epsilon_0} \int_{a}^{d-a} \left( \frac{1}{x} + \frac{1}{d-x} \right) dx$$
   $$U = \frac{\lambda}{2\pi\epsilon_0} \left[ \ln x - \ln(d-x) \right]_{a}^{d-a}$$
   $$U = \frac{\lambda}{2\pi\epsilon_0} \cdot 2 \ln\left(\frac{d-a}{a}\right) = \frac{\lambda}{\pi\epsilon_0} \ln\left(\frac{d-a}{a}\right)$$

   **💡 第二步：求电容并近似**
   $$C = \frac{\lambda}{U} = \frac{\pi\epsilon_0}{\ln\left(\frac{d-a}{a}\right)}$$
   因为 $d \gg a$，$d-a \approx d$，近似结果为：
   $$C \approx \frac{\pi\epsilon_0}{\ln\left(\frac{d}{a}\right)}$$
