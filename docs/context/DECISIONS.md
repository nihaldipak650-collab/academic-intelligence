# Decisions

这里只记录用户已经明确批准、且仍有效的决定。模型建议、模板分支提案和未合并实现不构成决定。

## D-001 — 本科生证据工具，不做导师评价

- **状态**：approved
- **日期**：2026-07-23（仓库文档形成日期）
- **决定**：产品面向本科生，尤其低年级用户；帮助理解导师公开研究证据，不做排名、推荐、人格或实验室氛围评价。
- **原因**：公开证据无法可靠支持主观评价，且本科生需要的是理解和核验路径。
- **影响**：页面、报告、搜索和文案不得暗示“最佳导师”或自动匹配结论。
- **取代旧决定**：否。

## D-002 — Academic 与 Experience 分车道

- **状态**：approved
- **日期**：2026-07-23
- **决定**：Academic Evidence 与 Experience Evidence 必须独立；Experience 默认内部、不进入公开主档，公开使用需单独隐私与授权审查。
- **原因**：学生经历包含再识别和关系风险，且不能由学术证据替代或推断。
- **影响**：页面隐藏不算隔离；公开数据、报告、构建产物和 Git 历史都要检查。
- **取代旧决定**：是；取代将两类证据混入同一公开导师报告的做法。

## D-003 — No Evidence 与禁止推断

- **状态**：approved
- **日期**：2026-07-23
- **决定**：没有可靠公开证据时明确标记 No Evidence；不得推断导师性格、带教态度、实验室氛围、真实本科任务、资源、反馈或招募。
- **原因**：避免把模型概括或论文信息写成导师与实验室事实。
- **影响**：所有导师内容需保持字段级证据和条件式表达；机械校验不能替代语义审查。
- **取代旧决定**：否。

## D-004 — 1.0 保持只读静态范围

- **状态**：approved
- **日期**：2026-07-24
- **决定**：1.0 为只读静态前端，不加入账号、数据库、AI 问答、导师排名或自动推荐。
- **原因**：先验证公开证据展示与基础使用体验。
- **影响**：超出该范围的功能需新任务和明确批准。
- **取代旧决定**：否。

## D-005 — 发布必须人工门控

- **状态**：approved
- **日期**：2026-07-24
- **决定**：Pages 部署只允许手动触发并显式确认；保留 0.5 作为手动回滚路径。未经用户明确授权不得 push、合并或部署。
- **原因**：导师资料和隐私风险需要发布前人工复核与可回滚性。
- **影响**：自动构建通过不等于允许上线；P0 未解除时禁止部署。
- **取代旧决定**：是；取代根 README 中“main push 自动部署旧站”的过时描述。

## D-006 — 仓库上下文优先于聊天记忆

- **状态**：approved
- **日期**：2026-07-31
- **决定**：后续 Codex 线程以 Git、仓库文件和 `docs/context/` 为事实来源；不能确认的内容标记 `unverified`，不从旧聊天补造事实。
- **原因**：降低长线程漂移，并让状态可复核、可交接。
- **影响**：动态状态更新 `CURRENT_STATE.md`/`HANDOFF.md`；稳定规则保留在 `AGENTS.md`。
- **取代旧决定**：是；取代继续依赖本长线程上下文的工作方式。
