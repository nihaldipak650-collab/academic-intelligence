# Scale and Stop Rules

## Calibration gate

For every materially new cohort, run exactly one advisor through the complete identity/publication loop, Validator, deterministic Renderer, fresh independent reviewer and Owner-visible latest-surface sample. Scale only when no P0/P1 workflow defect remains.

## Stop immediately when

- multiple plausible same-name identities remain;
- affiliation cannot be closed or sources are inaccessible;
- ORCIDs conflict or a single record is being over-promoted;
- DOI/title or formal/preprint identity is unclear;
- official profile contradicts publication metadata;
- schema/Validator cannot express the real state;
- topic attractiveness is the main identity argument;
- output would imply stronger evidence than exists;
- a new contract/Validator bypass appears.

`UNRESOLVED` is a correct state, not production failure. Resume only with new evidence or an explicitly reviewed contract repair. Never continue the cohort after a common-layer defect is found.
