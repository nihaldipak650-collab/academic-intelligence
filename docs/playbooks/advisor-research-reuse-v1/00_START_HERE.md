# Advisor Research Reuse Pack V1

Use this pack when asked to run another advisor cohort. It preserves the operational lessons of Phase 2 Cohort 8 rather than merely describing outputs.

## Non-negotiable model

```text
Official profile
  -> identity seed
  -> candidate author discovery
  -> broad publication retrieval
  -> DOI/metadata normalization
  -> same-name/affiliation/ORCID/network verification
  -> verified candidate | unresolved | excluded/conflict
  -> adoption decision
  -> publication-supported synthesis
  -> featured shortlist
  -> Owner review
  -> local latest-surface review
  -> freeze/release preparation
```

`candidate != verified identity != adopted != featured != released`.

Start with `01_WORKFLOW_SOP.md`, use `10_CODEX_PROMPT_TEMPLATE.md` to launch a batch, and execute `11_NEW_ADVISOR_BATCH_TEMPLATE.md` per advisor. The correct result may be `UNRESOLVED`.
