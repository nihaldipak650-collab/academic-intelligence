# Workflow SOP

1. Record branch, HEAD, status, allowed paths and protected paths.
2. Verify roster eligibility from the official structured source.
3. Ingest the official profile as E1; capture name variants, unit, role, email, research directions and official URL without inventing missing values.
4. Record publication-search state explicitly: `SEARCH_NOT_RUN`, `SEARCH_RUN_ZERO_RESULTS`, or `CANDIDATES_FOUND`. Official-profile-only is never presented as publication-complete.
5. Retain all plausible author candidates, including why each may be wrong.
6. Retrieve broadly, then normalize each paper using article-local identifiers.
7. Decide each publication identity independently. Preserve conflicting, rejected and unresolved rows.
8. Adopt only identity-verified evidence. Build synthesis only from adopted evidence and label its epistemic lane.
9. Create a featured shortlist separately; only Owner action makes it featured.
10. Run one-advisor Pilot through Validator, Renderer, fresh reviewer and an Owner-visible latest-surface page before scaling.
11. After scale, reconcile counts, cross-advisor contamination, hashes, tests, public-path diffs and human/release gates.

Never copy facts, ORCIDs, author identities, evidence IDs or conclusions across advisors.
