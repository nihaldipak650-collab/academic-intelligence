# Human Review Checklist

The Owner should not need to re-research every paper. Present evidence in this order:

## P0 — identity hazards

- unresolved and excluded/conflict records;
- ORCID anomalies, same-name clusters and DOI/version conflicts;
- contradictions between official profile and publication metadata.

## P1 — adopted set

- identity basis, author role, affiliation timeline and source provenance;
- whether any adopted paper should be demoted.

## P2 — featured set

- direction coverage, complementarity, recency, role, student readability and trajectory balance.

## P3 — verified candidates

- whether a non-adopted verified paper adds necessary coverage.

## P4 — rendered language

- fact/synthesis separation, overclaim, student-task language and visible uncertainty.

Allowed decisions: `ACCEPT`, `ACCEPT_WITH_NOTES`, `FIX`, `REJECT`. Publication-content approval is not global identity approval or release authorization.
