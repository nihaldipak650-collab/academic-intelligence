# 导师画像：`name_zh`（`name_en`）

本模板由 Renderer 固定生成，是结构化数据的可读导出报告和证据审阅视图，不是最终前端 UI。

1. 一分钟认识导师：研究概览、内容证据支持、导师论文归属与数据状态分开表达。
2. 基础身份与官方信息：逐字段展示公开值、公开来源和真实核验状态。
3. 研究方向。
4. 研究方向通俗解释。
5. 主要研究问题。
6. 常用技术与研究流程。
7. 代表性论文：只显示人工审核通过的 `featured_publication_evidence_ids`；待审时不展示条目。
8. 本科生可能参与的任务：保留不确定性声明。
9. 前置技能与学习成本。
10. 通用成长路径：不是导师官方培养方案。
11. 联系前准备与线下核验。
12. 证据与数据状态：只显示中文计数，以及指向 Validation Report 的版本关系、Schema 和字段绑定提示。
13. 更新时间与发布状态：区分 `record_created_at`、`migrated_at` 与 `last_verified_at`。
14. 使用边界说明。

正文只能引用 adopted 证据。机器枚举必须完整映射为中文；禁止显示内部仓库路径、行号、本地绝对路径、内部身份审查细节或完整候选论文表。Renderer 未读取 `validation-report-v1.json` 时不得宣称校验通过。
