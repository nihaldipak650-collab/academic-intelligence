# Owner Scoped Review Policy

The Cohort 8 Owner review truthfully covers:

- adoption decisions for all eight advisors;
- rejected and unresolved publication records;
- ORCID anomalies;
- featured-paper selections;
- focused final web spot-checks of high-risk and representative pages;
- acknowledged known open risks.

It does not claim exhaustive field-by-field or paper-by-paper re-research. The structured record therefore uses `approved_with_notes`, `reviewer_role=owner`, `exhaustive_review=false`, and `release_authorized=false`.

The publication-decision and known-risk files are referenced by repository-relative path and SHA-256. Missing scope, a missing advisor ID, unacknowledged risks, an invalid date/role, or an exhaustive-review overclaim blocks v1.0.7 release eligibility.
